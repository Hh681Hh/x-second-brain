X 书签助手 · 永久免费的本地浏览器插件（原创 MIT 开源）

1. 先双击项目里的“启动X书签助手.cmd”，保持后台运行。
2. Chrome 打开 chrome://extensions，或 Edge 打开 edge://extensions。
3. 开启“开发者模式”→“加载已解压的扩展程序”，选择本文件所在文件夹。
4. 打开 http://127.0.0.1:8787/，生成配对码；点击浏览器工具栏插件，粘贴并连接。
5. 刷新已经打开的 X 网页。之后亲手点原生书签按钮，插件会在页面显示已收藏后保存。

默认模式下长文先展开再收藏。后台另行启用 X_PUBLIC_FULLTEXT_PROVIDER=fxembed 时，可由第三方公开接口补取预览对应的全文；这会向 api.fxtwitter.com 发送帖子 ID，并非 X 官方接口，不保证持续可用。具体配置及已验证范围见项目 README。
已收藏过的文章，展开后点击插件的“保存当前内容”即可补全，不必取消收藏。
只读取当前已加载的文字，既不获取账号密码和 Cookie，也不调用 X 内部接口或自动滚动网页。
不自动补齐完整 Thread、历史收藏、手机 App 收藏、图片和站外链接全文。未展开的 Article 卡片只保存预览。
插件本身免费，无需 X 官方 API；后台 Codex 阅读使用你现有账号的额度，不能承诺模型服务无限免费。

插件队列保存在这个浏览器本机，不同步到第三方。待发送正文最多100条且总计150万字符；队列满会提示失败。
入库后的原文保存在项目 data/knowledge.sqlite3，可以通过 Codex Skill 导出。
卸载插件会删除未发送队列；已入库内容仍在本机。工具栏“!”表示待处理错误，点击查看具体原因。

本插件尚未上架扩展商店，需要以上方式安装。测试夹具不等于真实 X 账号验证。
X 页面结构或平台规则可能变化；如原生按钮监听失效，可用插件按钮明确保存当前页。
